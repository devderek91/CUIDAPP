# 🧸 CUIDAPP - Marketplace de Servicios de Cuidado Infantil

Plataforma web que conecta a padres/madres con cuidadores de confianza para el cuidado de niños. Sistema completo de registro, búsqueda, reserva y valoración de servicios.

##  Funcionalidades

### Para Padres/Madres:
- ✅ Registro y verificación de perfil
- ✅ Búsqueda de cuidadores por disponibilidad y urgencia
- ✅ Sistema de reservas con pago integrado
- ✅ Dashboard personal con historial de cobros
- ✅ Valoración de servicios recibidos
- ✅ Notificaciones de reservas

### Para Cuidadores:
- ✅ Registro y creación de perfil profesional
- ✅ Gestión de disponibilidad horaria
- ✅ Dashboard con servicios activos
- ✅ Historial de servicios completados

### Sistema General:
- ✅ Diseño responsive (móvil, tablet, desktop)
- ✅ Interfaz intuitiva y moderna
- ✅ Validación de formularios con JavaScript

## ️ Stack Tecnológico

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Diseño:** Responsive Design, Mobile-first
- **Control de versiones:** Git, GitHub
